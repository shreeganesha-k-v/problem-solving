You are given an integer array nums and an integer k.An integer x is almost missing from nums if x appears in exactly one subarray of size k within nums.Return the largest almost missing integer from nums. If no such integer exists, return -1.A subarray is a contiguous sequence of elements within an array.
Example 1:Input: nums = [3,9,2,1,7], k = 3			Output: 7
Explanation:1 appears in 2 subarrays of size 3: [9, 2, 1] and [2, 1, 7]. 2 appears in 3 subarrays of size 3: [3, 9, 2], [9, 2, 1], [2, 1, 7]. 3 appears in 1 subarray of size 3: [3, 9, 2]. 7 appears in 1 subarray of size 3: [2, 1, 7]. 9 appears in 2 subarrays of size 3: [3, 9, 2], and [9, 2, 1]. We return 7 since it is the largest integer that appears in exactly one subarray of size k.
Example 2:Input: nums = [3,9,7,2,1,7], k = 4			Output: 3
Explanation:1 appears in 2 subarrays of size 4: [9, 7, 2, 1], [7, 2, 1, 7]. 2 appears in 3 subarrays of size 4: [3, 9, 7, 2], [9, 7, 2, 1], [7, 2, 1, 7]. 3 appears in 1 subarray of size 4: [3, 9, 7, 2]. 7 appears in 3 subarrays of size 4: [3, 9, 7, 2], [9, 7, 2, 1], [7, 2, 1, 7]. 9 appears in 2 subarrays of size 4: [3, 9, 7, 2], [9, 7, 2, 1]. We return 3 since it is the largest and only integer that appears in exactly one subarray of size k.
Example 3:Input: nums = [0,0], k = 1					Output: -1
Explanation:There is no integer that appears in only one subarray of size 1.

import java.util.*;

class Solution {

    public int largestAlmostMissing(int[] nums, int k) {

        int n = nums.length;

        // Frequency of elements in the current sliding window.
        Map<Integer, Integer> windowFreq = new HashMap<>();

        // Number of size-k subarrays in which each number appears.
        Map<Integer, Integer> windowCount = new HashMap<>();

        // Build the first window.
        for (int i = 0; i < k; i++) {
            windowFreq.put(nums[i],
                    windowFreq.getOrDefault(nums[i], 0) + 1);
        }

        // Every distinct number in the first window
        // appears in exactly one subarray so far.
        for (int num : windowFreq.keySet()) {
            windowCount.put(num, 1);
        }

        // Slide the window from left to right.
        for (int right = k; right < n; right++) {

            int entering = nums[right];
            int leaving = nums[right - k];

            // Remove the element leaving the window.
            int freq = windowFreq.get(leaving);

            if (freq == 1) {
                // It completely disappears from the current window.
                windowFreq.remove(leaving);
            } else {
                windowFreq.put(leaving, freq - 1);
            }

            // Add the new element.
            windowFreq.put(
                    entering,
                    windowFreq.getOrDefault(entering, 0) + 1
            );

            /*
             * The current window contains each distinct element
             * exactly once as a subarray occurrence.
             *
             * Increment windowCount only for elements that are
             * actually present in the current window.
             */
            for (int num : windowFreq.keySet()) {
                windowCount.put(
                        num,
                        windowCount.getOrDefault(num, 0) + 1
                );
            }
        }

        // Find the largest number that appears in exactly
        // one size-k subarray.
        int answer = -1;

        for (Map.Entry<Integer, Integer> entry : windowCount.entrySet()) {

            if (entry.getValue() == 1) {
                answer = Math.max(answer, entry.getKey());
            }
        }

        return answer;
    }
}

You have a bookshelf in the form of an array ‘arr’ in which names of the books(single word name) are given. You are also given names of two books, ‘book1’ and ‘book2’. You are supposed to find the minimum distance between ‘book1’ and ‘book2’.Distance between two books is defined as the absolute difference between the indices of the books i.e for two books at index 'i' and 'j' the distance is equal to |i-j|.
Note:1. There may be multiple occurrences of any book. 2. book1 and book2 are present on the bookshelf. 3. The name of the books is in lower-case. 4. book1 is not equal to book2.
Sample Input 1: arr=coding ninjas help to crack product based companies	book1=coding book2=product
arr=eat code sleep repeat eat code sleep repeat  book1=eat book2=repeat
Sample Output 1:5			1
Explanation for Sample Input 1:In the first test case, there are 8 books on the bookshelf.book1 = “coding”, book2 = “product”. The distance between book1 and book2 is 5. So, the answer is 5.In the second test case, there are 8 books on the bookshelf. and there are 2 occurrences in every book.book1 = “eat”, book2 = “repeat”.  book1 is present at indices 0 and 4. book2 is present at indices 3 and 7. The distances are 3, 7, 1, 4. The minimum of these is 1. So, the answer is 1.
Sample Input 2: arr=alpha beta gamma theta beta	book1=theta book2=beta
arr=be cool whatever the situation is	book1=situation book2=cool
Sample Output 2:1			3

public class Solution {

    public static int minDistance(String[] arr, String book1, String book2) {

        // Store the most recent index of book1.
        int lastBook1 = -1;

        // Store the most recent index of book2.
        int lastBook2 = -1;

        // Start with maximum possible answer.
        int minDistance = Integer.MAX_VALUE;

        // Traverse the bookshelf only once.
        for (int i = 0; i < arr.length; i++) {

            // If current book is book1,
            // update its most recent position.
            if (arr[i].equals(book1)) {
                lastBook1 = i;
            }

            // If current book is book2,
            // update its most recent position.
            if (arr[i].equals(book2)) {
                lastBook2 = i;
            }

            // If we have seen both books,
            // calculate their distance.
            if (lastBook1 != -1 && lastBook2 != -1) {

                minDistance = Math.min(
                        minDistance,
                        Math.abs(lastBook1 - lastBook2)
                );
            }
        }

        return minDistance;
    }
}

Explanation: The figure above shows an optimal allocation of four groups. Seats marked in blue are already reserved, and each set of four contiguous seats marked in orange is assigned to one group.
Example 2:Input: n = 2, reservedSeats = [[2,1],[1,8],[2,6]]								Output: 2
Example 3:Input: n = 4, reservedSeats = [[4,3],[1,4],[4,6],[1,7]]						Output: 4

class Solution {

    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {

        // Store reserved seats for each row.
        Map<Integer, Set<Integer>> rows = new HashMap<>();

        for (int[] seat : reservedSeats) {
            rows.computeIfAbsent(seat[0], k -> new HashSet<>())
                .add(seat[1]);
        }

        // Rows with no reservations can always fit 2 groups.
        int result = (n - rows.size()) * 2;

        for (Set<Integer> seats : rows.values()) {

            boolean left = true;
            boolean middle = true;
            boolean right = true;

            // Check seats 2,3,4,5
            for (int seat = 2; seat <= 5; seat++) {
                if (seats.contains(seat)) {
                    left = false;
                    break;
                }
            }

            // Check seats 4,5,6,7
            for (int seat = 4; seat <= 7; seat++) {
                if (seats.contains(seat)) {
                    middle = false;
                    break;
                }
            }

            // Check seats 6,7,8,9
            for (int seat = 6; seat <= 9; seat++) {
                if (seats.contains(seat)) {
                    right = false;
                    break;
                }
            }

            if (left && right) {
                // Can fit two non-overlapping groups.
                result += 2;
            } else if (left || middle || right) {
                // Can fit at least one group.
                result++;
            }
        }

        return result;
    }
}

class Solution {

    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {

        /*
         * Store only rows that have reserved seats.
         *
         * Bit i represents whether seat i is reserved.
         */
        Map<Integer, Integer> reserved = new HashMap<>();

        for (int[] seat : reservedSeats) {

            int row = seat[0];
            int seatNumber = seat[1];

            // Set the bit corresponding to this seat.
            reserved.put(
                    row,
                    reserved.getOrDefault(row, 0) | (1 << seatNumber)
            );
        }

        int result = 0;

        /*
         * Rows without any reservations can always accommodate
         * two groups:
         *
         * [2,3,4,5] and [6,7,8,9]
         */
        result += (n - reserved.size()) * 2;

        /*
         * Process only rows that contain reserved seats.
         */
        for (int mask : reserved.values()) {

            // Seats 2,3,4,5
            boolean leftAvailable =
                    (mask & ((1 << 2) | (1 << 3) |
                             (1 << 4) | (1 << 5))) == 0;

            // Seats 4,5,6,7
            boolean middleAvailable =
                    (mask & ((1 << 4) | (1 << 5) |
                             (1 << 6) | (1 << 7))) == 0;

            // Seats 6,7,8,9
            boolean rightAvailable =
                    (mask & ((1 << 6) | (1 << 7) |
                             (1 << 8) | (1 << 9))) == 0;

            /*
             * Left and right blocks don't overlap,
             * so both can be used simultaneously.
             */
            if (leftAvailable && rightAvailable) {
                result += 2;
            }

            /*
             * If left and right cannot both be used,
             * the middle block may still accommodate one group.
             */
            else if (leftAvailable || middleAvailable || rightAvailable) {
                result += 1;
            }
        }

        return result;
    }
}

You’re given a board of length 'L' and width 'W'. Your task is to break this board into 'L' * 'W' smaller squares, such that the total cost involved in breaking is the minimum possible.
Sample Input 1:
3 3
1 2
2 1
Sample Output 1:
11
Explanation of Sample Input 1:
Start by cutting the vertical column with cost = 2, hence cost becomes 2. Then make two cuts at the horizontal row with the cost = 2, Cost = 2*2 + 2 =6. Then vertically cut two columns with cost = 2, Cost = 6 + 1*2 = 8. Finally make three horizontal cuts with cost = 1. Final cost becomes 8 + 1*3 = 11.
Sample Input 2:
2 2
2
1
Sample Output 2:
4
Explanation of Sample Input 2:
In this case, we’ll be doing a total of 2 cuts. In the first cut, we’ll be cutting the first segment and our cost will now be 1*2 = 2 and in the second and the final cut, we’ll be cutting 2 segments each of cost one. Hence our final cost be 2 + 2*1 = 4.

public class Solution {

    public static long minimumCost(int L, int W,
                                    int[] costL, int[] costW) {

        /*
         * Sort both arrays in ascending order.
         * We will process them from right to left,
         * which means highest cost first.
         */
        Arrays.sort(costL);
        Arrays.sort(costW);

        int i = costL.length - 1;
        int j = costW.length - 1;

        /*
         * Initially the board is one piece in each direction.
         */
        int horizontalPieces = 1;
        int verticalPieces = 1;

        long totalCost = 0;

        /*
         * Process both types of cuts while both are available.
         */
        while (i >= 0 && j >= 0) {

            /*
             * Choose the more expensive cut first.
             */
            if (costL[i] >= costW[j]) {

                /*
                 * Horizontal cut crosses all current
                 * vertical pieces.
                 */
                totalCost += (long) costL[i] * verticalPieces;

                // This creates one additional horizontal piece.
                horizontalPieces++;

                i--;

            } else {

                /*
                 * Vertical cut crosses all current
                 * horizontal pieces.
                 */
                totalCost += (long) costW[j] * horizontalPieces;

                // This creates one additional vertical piece.
                verticalPieces++;

                j--;
            }
        }

        /*
         * If horizontal cuts are still remaining,
         * all vertical pieces already exist.
         */
        while (i >= 0) {

            totalCost += (long) costL[i] * verticalPieces;

            horizontalPieces++;
            i--;
        }

        /*
         * If vertical cuts are still remaining,
         * all horizontal pieces already exist.
         */
        while (j >= 0) {

            totalCost += (long) costW[j] * horizontalPieces;

            verticalPieces++;
            j--;
        }

        return totalCost;
    }
}

You are given a 1-indexed array of distinct integers nums of length n.You need to distribute all the elements of nums between two arrays arr1 and arr2 using n operations. In the first operation, append nums[1] to arr1. In the second operation, append nums[2] to arr2. Afterwards, in the ith operation:If the last element of arr1 is greater than the last element of arr2, append nums[i] to arr1. Otherwise, append nums[i] to arr2.
The array result is formed by concatenating the arrays arr1 and arr2. For example, if arr1 == [1,2,3] and arr2 == [4,5,6], then result = [1,2,3,4,5,6].Return the array result.
Example 1:Input: nums = [2,1,3]				Output: [2,3,1]
Explanation: After the first 2 operations, arr1 = [2] and arr2 = [1].In the 3rd operation, as the last element of arr1 is greater than the last element of arr2 (2 > 1), append nums[3] to arr1.After 3 operations, arr1 = [2,3] and arr2 = [1].Hence, the array result formed by concatenation is [2,3,1].
Example 2:Input: nums = [5,4,3,8]			Output: [5,3,4,8]
Explanation: After the first 2 operations, arr1 = [5] and arr2 = [4].In the 3rd operation, as the last element of arr1 is greater than the last element of arr2 (5 > 4), append nums[3] to arr1, hence arr1 becomes [5,3].In the 4th operation, as the last element of arr2 is greater than the last element of arr1 (4 > 3), append nums[4] to arr2, hence arr2 becomes [4,8].After 4 operations, arr1 = [5,3] and arr2 = [4,8].Hence, the array result formed by concatenation is [5,3,4,8].

class Solution {

    public int[] resultArray(int[] nums) {

        // Lists are convenient because we don't know
        // how many elements will go into each array.
        List<Integer> arr1 = new ArrayList<>();
        List<Integer> arr2 = new ArrayList<>();

        // First operation:
        // nums[0] goes into arr1.
        arr1.add(nums[0]);

        // Second operation:
        // nums[1] goes into arr2.
        arr2.add(nums[1]);

        // Process the remaining elements.
        for (int i = 2; i < nums.length; i++) {

            // Compare the last elements of arr1 and arr2.
            if (arr1.get(arr1.size() - 1) >
                    arr2.get(arr2.size() - 1)) {

                // Last element of arr1 is greater,
                // so add current element to arr1.
                arr1.add(nums[i]);

            } else {

                // Otherwise, add current element to arr2.
                arr2.add(nums[i]);
            }
        }

        // Create the final result array.
        int[] result = new int[nums.length];

        int index = 0;

        // First append all elements from arr1.
        for (int num : arr1) {
            result[index++] = num;
        }

        // Then append all elements from arr2.
        for (int num : arr2) {
            result[index++] = num;
        }

        return result;
    }
}

public class Solution {

    public static long[] addFraction(int a, int b, int c, int d) {

        // Calculate numerator and denominator
        long numerator = (long) a * d + (long) c * b;
        long denominator = (long) b * d; // cast one operand before multiplying to avoid integer overflow

        // Find GCD to simplify the fraction
        long gcd = findGcd(numerator, denominator);

        numerator /= gcd;
        denominator /= gcd;

        return new long[]{numerator, denominator};
    }

    // Euclidean algorithm to find GCD
    private static long findGcd(long a, long b) {

        while (b != 0) {
            long temp = b;
            b = a % b;
            a = temp;
        }

        return a;
    }
}

public class Solution {

    public static long minimumChanges(int[] arr) {

        // Sort the array to find the median.
        Arrays.sort(arr);

        // Median minimizes the sum of absolute differences.
        int median = arr[arr.length / 2];

        long totalChanges = 0;

        // Calculate the total number of candies
        // that need to be increased/decreased.
        for (int num : arr) {
            totalChanges += Math.abs((long) num - median);
        }

        return totalChanges;
    }

public class Solution {

    public static int optimalChoice(int n, int numMisha) {

        // If Misha selected 1, Andrew must choose 2.
        if (numMisha == 1) {
            return 2;
        }

        // If Misha selected N, Andrew must choose N - 1.
        if (numMisha == n) {
            return n - 1;
        }

        int leftWins = numMisha - 1;
        int rightWins = n - numMisha;

        // In case of a tie, either side gives the same probability.
        // We choose the left side.
        if (leftWins >= rightWins) {
            return numMisha - 1;
        }

        return numMisha + 1;
    }
}

You are given a positive integer n. Determine whether n is divisible by the sum of the following two values:The digit sum of n (the sum of its digits).The digit product of n (the product of its digits).Return true if n is divisible by this sum; otherwise, return false.
Example 1:Input: n = 99				Output: true
Explanation:Since 99 is divisible by the sum (9 + 9 = 18) plus product (9 * 9 = 81) of its digits (total 99), the output is true.
Example 2:Input: n = 23				Output: false
Explanation:Since 23 is not divisible by the sum (2 + 3 = 5) plus product (2 * 3 = 6) of its digits (total 11), the output is false.

class Solution {
    public boolean checkDivisibility(int n) {
        int original = n;

        int digitSum = 0;
        int digitProduct = 1;

        // Process every digit.
        while (n > 0) {

            // Extract the last digit.
            int digit = n % 10;

            // Add digit to the digit sum.
            digitSum += digit;

            // Multiply digit into the digit product.
            digitProduct *= digit;

            // Remove the last digit.
            n /= 10;
        }

        // The divisor is:
        // digit sum + digit product
        int divisor = digitSum + digitProduct;

        return original % divisor == 0;
    }
}

Sample Output 1:1 -1 2 -2 3 -3 			1 -10 5 -1 2 -3 0 -2 
Explanation of Sample Input 1:In the first test case, the output is an array of alternative positive and negative numbers, and also order is maintained (relative order of positive numbers are 1 -> 2 -> 3 and for negative numbers are -1 -> 2 -> -3 )In the first test case, it is already in valid arrangement.
Sample Input 2:-1 0 0 -1			Sample Output 2:0 -1 0 -1

public class Solution {

    public static void rearrange(int[] arr) {

        int n = arr.length;

        // Temporary arrays to preserve the relative order
        // of positive and negative numbers.
        int[] positive = new int[n / 2];
        int[] negative = new int[n / 2];

        int positiveIndex = 0;
        int negativeIndex = 0;

        // Separate the elements while maintaining their
        // original relative order.
        for (int num : arr) {

            // Zero is considered positive.
            if (num >= 0) {
                positive[positiveIndex++] = num;
            } else {
                negative[negativeIndex++] = num;
            }
        }

        // Put them back alternately:
        // positive, negative, positive, negative...
        int index = 0;

        for (int i = 0; i < n / 2; i++) {

            arr[index++] = positive[i];
            arr[index++] = negative[i];
        }
    }
}

class Solution {

    public boolean sumGame(String num) {

        int n = num.length();

        int leftSum = 0;
        int rightSum = 0;

        int leftQuestion = 0;
        int rightQuestion = 0;

                rightQuestion++;
            } else {
                rightSum += num.charAt(i) - '0';
            }
        }

        // Difference between the known sums.
        int sumDifference = leftSum - rightSum;

        // Difference between the number of '?'.
        int questionDifference = leftQuestion - rightQuestion;

        /*
         * Bob can force equality only when the existing
         * sum difference can exactly compensate for the
         * maximum possible contribution difference created
         * by the '?' characters.
         *
         * Each '?' can contribute 0..9.
         *
         * The critical condition is:
         *
         * 2 * |sumDifference|
         *     == 9 * |questionDifference|
         */
        return 2 * Math.abs(sumDifference)
                != 9 * Math.abs(questionDifference);
    }
}

public class Solution {

    public static String areMetaStrings(String str1, String str2) {

        // Different lengths can never be made equal
        // by swapping characters.
        if (str1.length() != str2.length()) {
            return "NO";
        }

        int firstMismatch = -1;
        int secondMismatch = -1;

        // Find positions where the strings differ.
        for (int i = 0; i < str1.length(); i++) {

            if (str1.charAt(i) != str2.charAt(i)) {

                // First mismatch
                if (firstMismatch == -1) {
                    firstMismatch = i;
                }
                // Second mismatch
                else if (secondMismatch == -1) {
                    secondMismatch = i;
                }
                // More than two mismatches means
                // one swap cannot fix the strings.
                else {
                    return "NO";
                }
            }
        }

        // Equal strings are explicitly NOT meta strings.
        if (firstMismatch == -1) {
            return "NO";
        }

        // Exactly one mismatch is impossible with one swap,
        // because a swap changes two positions.
        if (secondMismatch == -1) {
            return "NO";
        }

        // The two mismatched characters must be swapped.
        if (str1.charAt(firstMismatch) == str2.charAt(secondMismatch)
                && str1.charAt(secondMismatch) == str2.charAt(firstMismatch)) {

            return "YES";
        }

        return "NO";
    }
}

For example, the array [2,10,3] is lexicographically smaller than the array [10,2,3] because they differ at index 0 and 2 < 10.
Example 1:Input: nums = [1,5,3,9,8], limit = 2				Output: [1,3,5,8,9]
Explanation: Apply the operation 2 times- Swap nums[1] with nums[2]. The array becomes [1,3,5,9,8] - Swap nums[3] with nums[4]. The array becomes [1,3,5,8,9]
We cannot obtain a lexicographically smaller array by applying any more operations.
Note that it may be possible to get the same result by doing different operations.
Example 2:Input: nums = [1,7,6,18,2,1], limit = 3				Output: [1,6,7,18,1,2]
Explanation: Apply the operation 3 times:
- Swap nums[1] with nums[2]. The array becomes [1,6,7,18,2,1]
- Swap nums[0] with nums[4]. The array becomes [2,6,7,18,1,1]
- Swap nums[0] with nums[5]. The array becomes [1,6,7,18,1,2]
We cannot obtain a lexicographically smaller array by applying any more operations.
Example 3:Input: nums = [1,7,28,19,10], limit = 3			Output: [1,7,28,19,10]
Explanation: [1,7,28,19,10] is the lexicographically smallest array we can obtain because we cannot apply the operation on any two indices.

class Solution {

    public int[] lexicographicallySmallestArray(int[] nums, int limit) {

        int n = nums.length;

        /*
         * Create pairs:
         * [value, originalIndex]
         *
         * We need the original index because after sorting
         * the values, we still need to know where each value
         * came from.
         */
        int[][] pairs = new int[n][2];

        for (int i = 0; i < n; i++) {
            pairs[i][0] = nums[i]; // value
            pairs[i][1] = i;       // original index
        }

        /*
         * Sort by value.
         */
        Arrays.sort(pairs, Comparator.comparingInt(a -> a[0]));

        int start = 0;

        while (start < n) {

            int end = start;

            /*
             * Find all values that belong to the same group.
             *
             * If consecutive sorted values differ by <= limit,
             * they can be connected through swaps.
             */
            while (end + 1 < n
                    && pairs[end + 1][0] - pairs[end][0] <= limit) {

                end++;
            }

            /*
             * Extract the values and original indices
             * belonging to this group.
             */
            List<Integer> values = new ArrayList<>();
            List<Integer> indices = new ArrayList<>();

            for (int i = start; i <= end; i++) {
                values.add(pairs[i][0]);
                indices.add(pairs[i][1]);
            }

            /*
             * values are already sorted because pairs was sorted.
             *
             * Sort the original indices as well.
             * To obtain the lexicographically smallest result,
             * put the smallest value at the smallest index.
             */
            Collections.sort(indices);

            /*
             * Assign sorted values to sorted original positions.
             */
            for (int i = 0; i < values.size(); i++) {
                nums[indices.get(i)] = values.get(i);
            }

            // Move to the next group.
            start = end + 1;
        }

        return nums;
    }
}

    public static String reformatString(String s, int k) {

        // Remove all hyphens and convert to uppercase.
        String str = s.replace("-", "").toUpperCase();

        int n = str.length();

        // Find the size of the first group.
        int firstGroupSize = n % k;

        // If divisible by k, the first group has k characters.
        if (firstGroupSize == 0) {

            index = end;
        }

        return result.toString();
    }

import java.util.*;

public class Solution {

    public int totalNumbers(int[] digits) {

        // Count the frequency of each digit.
        int[] freq = new int[10];

        for (int digit : digits) {
            freq[digit]++;
        }

        int count = 0;

        // Choose the hundreds digit.
        // It cannot be zero.
        for (int hundreds = 1; hundreds <= 9; hundreds++) {

            if (freq[hundreds] == 0) {
                continue;
            }

            freq[hundreds]--;

            // Choose the tens digit.
            for (int tens = 0; tens <= 9; tens++) {

                if (freq[tens] == 0) {
                    continue;

                freq[tens]--;

                // Choose the units digit.
                // It must be even.
                for (int units = 0; units <= 8; units += 2) {

                    if (freq[units] > 0) {
                        count++;
                    }
                }

                // Restore the tens digit.
                freq[tens]++;
            }

            // Restore the hundreds digit.
            freq[hundreds]++;
        }

        return count;
    }

public class Solution {

    public static String addBinary(String A, String B) {

        int i = A.length() - 1;
        int j = B.length() - 1;

        int carry = 0;

        StringBuilder result = new StringBuilder();

        // Continue while either string has digits
        // or a carry is still remaining.
        while (i >= 0 || j >= 0 || carry != 0) {

            int sum = carry;

            // Add the current digit of A.
            if (i >= 0) {
                sum += A.charAt(i) - '0';
                i--;
            }

            // Add the current digit of B.
            if (j >= 0) {
                sum += B.charAt(j) - '0';
                j--;
            }

            // Store the current binary digit.
            result.append(sum % 2);

            // Calculate carry for the next position.
            carry = sum / 2;
        }

        // Digits were added from right to left,
        // so reverse them to get the correct answer.
        return result.reverse().toString();
    }

You are given an array of integers arr and an integer target.You have to find two non-overlapping sub-arrays of arr each with a sum equal target. Example 1:Input: arr = [3,2,2,4,3], target = 3				Output: 2
Explanation: Only two sub-arrays have sum = 3 ([3] and [3]). The sum of their lengths is 2.
Example 2:Input: arr = [7,3,4,7], target = 7				Output: 2
Explanation: Although we have three non-overlapping sub-arrays of sum = 7 ([7], [3,4] and [7]), but we will choose the first and third sub-arrays as the sum of their lengths is 2.
Example 3:Input: arr = [4,3,2,6,2,3,4], target = 6			Output: -1
Explanation: We have only one sub-array of sum = 6.

public class Solution {

    public static int minSumOfLengths(int[] arr, int target) {

        int n = arr.length;

        // best[i] stores the minimum length of a valid subarray
        // found in the range [0 ... i].
        int[] best = new int[n];

        Arrays.fill(best, Integer.MAX_VALUE);

        int left = 0;
        int sum = 0;

        int answer = Integer.MAX_VALUE;

        for (int right = 0; right < n; right++) {

            sum += arr[right];

            // Shrink the window if its sum becomes greater than target.
            while (sum > target && left <= right) {
                sum -= arr[left];
                left++;
            }

            // If the current window has the required sum.
            if (sum == target) {

                int currentLength = right - left + 1;

                // A previous subarray must end before 'left'.
                if (left > 0 &&
                    best[left - 1] != Integer.MAX_VALUE) {

                    answer = Math.min(
                            answer,
                            currentLength + best[left - 1]
                    );
                }

                // Store the shortest valid subarray seen so far.
                best[right] = currentLength;
            }

            // Carry forward the previous best result.
            if (right > 0) {
                best[right] = Math.min(best[right], best[right - 1]);
            }
        }

        return answer == Integer.MAX_VALUE ? -1 : answer;
    }

import java.util.*;

public class Solution {

    public static ArrayList<ArrayList<Integer>> twistAndChange(
            ArrayList<ArrayList<Integer>> A) {

        int n = A.size();

        for (int i = 0; i < n; i++) {

            // Reverse the row and invert the value
            for (int j = 0; j < n; j++) {

                int value = A.get(i).get(n - 1 - j);

                // 0 -> 1 and 1 -> 0
                A.get(i).set(j, 1 - value);
            }
        }

        return A;
    }
}

Sample Input 1:			1 -4 -2 5 3			2 1    
Sample Output 1:		Yes					Yes
Explanation for Sample Input 1:
For the first test case we have, array: [1, -4, -2, 5, 3] and N = 5. On rearranging the array such that all negative numbers appear before all positive numbers we get the resulting array [-2, -4, 1, 5, 3].
For the second test case we have, array: [2, 1] and N = 2. There are no negative numbers. Hence, we do not require any rearrangement.
Sample Input 2:	1 -5 -5 3				-1 -2 3 4 5				-2
Sample Output 2:Yes 					Yes						Yes
Explanation for Sample Input 2:
For the first test case we have, array: [1, -5, -5,  3] and N = 4. On rearranging the array such that all negative numbers appear before all positive numbers we get the resulting array [-5, -5, 1, 3].For the second test case we have, array: [-1, -2, 3, 4, 5] and N = 5. There are already arranged in required way. Hence, we do not require any rearrangement.For the third test case we have, array: [-2 ] and N = 1. The array is already arranged in required way. Hence, we do not require any rearrangement.

public class Solution {

    public static void rearrange(int[] arr) {

        int left = 0;
        int right = arr.length - 1;

        while (left <= right) {

            // Already a negative number
            if (arr[left] < 0) {
                left++;
            }

            // Already a positive/non-negative number
            else if (arr[right] >= 0) {
                right--;
            }

            // arr[left] is positive/non-negative
            // arr[right] is negative -> swap
            else {
                int temp = arr[left];
                arr[left] = arr[right];
                arr[right] = temp;

                left++;
                right--;
            }
        }
    }
}

Ninja is observing an array of ‘N’ numbers and wants to make as many unique subsets as possible. Can you help the Ninja to find all the unique subsets?Note: Two subsets are called same if they have same set of elements.For example {3,4,1} and {1,4,3} are not unique subsets.You are given an array ‘ARR’ having N elements. Your task is to print all unique subsets.
For ExampleFor the given if ARR = [1,1,3],the answer will be [ ],[1],[1,1],[1,3],[3],[1,1,3].
Sample Input 1:	1 1 3				1 3 3 3
Explanation of sample input 1:For the first test case,The unique subsets will be  [ ],[1],[1,1],[1,3],[3],[1,1,3]. 
For the second test case:The unique subsets will be  [ ],[1,3],[1,3,3],[1,3,3,3],[3],[3,3],[3,3,3]. 

public class Solution {

    public static ArrayList<ArrayList<Integer>> uniqueSubsets(
            ArrayList<Integer> arr) {

        // Sorting makes duplicate elements adjacent
        Collections.sort(arr);

        ArrayList<ArrayList<Integer>> result = new ArrayList<>();

        generateSubsets(arr, 0, new ArrayList<>(), result);

        return result;
    }

    private static void generateSubsets(
            ArrayList<Integer> arr,
            int start,
            ArrayList<Integer> current,
            ArrayList<ArrayList<Integer>> result) {

        // Every current selection is a valid subset
        result.add(new ArrayList<>(current));

        for (int i = start; i < arr.size(); i++) {

            // Skip duplicate choices at the same recursion level
            if (i > start && arr.get(i).equals(arr.get(i - 1))) {
                continue;
            }

            // Choose
            current.add(arr.get(i));

            // Explore
            generateSubsets(arr, i + 1, current, result);

            // Backtrack
            current.remove(current.size() - 1);
        }
    }
}

You are given two integers ‘X’ and ‘Y’. Your task is to find if the given integers are an amicable pair.A pair of numbers are called Amicable if the sum of the proper divisor of each number is equal to the other number. Print ‘True’ if the numbers form amicable pair otherwise print ‘False’A positive proper divisor is a positive divisor of a number, excluding itself. For example, 1, 2, and 3 are positive proper divisors of 6, but 6 itself is not.
For example:Let 'X' = 220 and 'Y' = 284 form an amicable pair as the sum of the proper divisor of one is equal to the other. 
Sample Input 1:	4 8				220 284
Sample Output 1:False			True
Explanation For Sample Input 1:In test case 1:Proper divisors of 4 are 1 and 2 with sum 3!=8. Proper divisors of 8 are 1, 2, and 4 with sum 7!=4Thus they are not amicable pairs.
In test case 2:Proper divisors of X=220 are 1, 2, 4, 5, 10, 11, 20, 22, 44, 55 and 110.
The sum of these is 284 = Y.Proper divisors of Y=284 are 1, 2, 4, 71, and 142.The sum of these is 220 = X.Thus they are amicable pairs.
Sample Input 2:	67095 71145				253 487			280 81
Sample Output 2:True					False			False
Explanation For Sample Input 2:67095 & 71145 are amicable pairs while 253 & 487 and 280 and 81 are not amicable numbers. 

public class Solution {

    public static boolean isAmicable(int x, int y) {

        // Usually amicable numbers are positive and distinct.
        if (x <= 0 || y <= 0 || x == y) {
            return false;
        }

        return sumOfProperDivisors(x) == y
                && sumOfProperDivisors(y) == x;
    }

    private static int sumOfProperDivisors(int n) {

        // 1 is a proper divisor of every n > 1
        int sum = 1;

        for (int i = 2; i * i <= n; i++) {

            if (n % i == 0) {

                // i is a divisor
                sum += i;

                // n / i is the paired divisor
                if (i != n / i) {
                    sum += n / i;
                }
            }
        }

        return sum;
    }
}

You are given an integer array nums and an integer x. In one operation, you can either remove the leftmost or the rightmost element from the array nums and subtract its value from x. Note that this modifies the array for future operations.Return the minimum number of operations to reduce x to exactly 0 if it is possible, otherwise, return -1.
Example 1:Input: nums = [1,1,4,2,3], x = 5			Output: 2
Explanation: The optimal solution is to remove the last two elements to reduce x to zero.
Example 2:Input: nums = [5,6,7,8,9], x = 4			Output: -1
Example 3:Input: nums = [3,2,20,1,1,3], x = 10		Output: 5
Explanation: The optimal solution is to remove the last three elements and the first two elements (5 operations in total) to reduce x to zero.

//If we remove elements from the left and right whose sum is x, the elements we don't remove form one contiguous subarray. sum(remaining subarray) = total - x . Find the longest subarray whose sum is total - x. then Find the longest subarray whose sum is total - x.
class Solution {

    public int minOperations(int[] nums, int x) {

        int total = 0;

        for (int num : nums) {
            total += num;
        }

        // Sum that should remain in the array
        int target = total - x;

        // If target is 0, remove the entire array
        if (target == 0) {
            return nums.length;
        }

        int left = 0;
        int sum = 0;
        int maxLength = -1;

        for (int right = 0; right < nums.length; right++) {

            sum += nums[right];

            // Shrink window if sum becomes too large
            while (sum > target && left <= right) {
                sum -= nums[left];
                left++;
            }

            // Found a subarray with required sum
            if (sum == target) {
                maxLength = Math.max(
                        maxLength,
                        right - left + 1
                );
            }
        }

        // No valid subarray
        if (maxLength == -1) {
            return -1;
        }

        // Remove everything outside the longest subarray
        return nums.length - maxLength;
    }
}

You are given an integer array nums.Return the smallest index i such that the sum of the digits of nums[i] is equal to i.If no such index exists, return -1.
Example 1:Input: nums = [1,3,2]				Output: 2
Explanation:For nums[2] = 2, the sum of digits is 2, which is equal to index i = 2. Thus, the output is 2.
Example 2:Input: nums = [1,10,11]			Output: 1
Explanation:For nums[1] = 10, the sum of digits is 1 + 0 = 1, which is equal to index i = 1.For nums[2] = 11, the sum of digits is 1 + 1 = 2, which is equal to index i = 2.Since index 1 is the smallest, the output is 1.
Example 3:Input: nums = [1,2,3]				Output: -1
Explanation:Since no index satisfies the condition, the output is -1.

class Solution {

    public int smallestIndex(int[] nums) {

        for (int i = 0; i < nums.length; i++) {

            if (digitSum(nums[i]) == i) {
                return i;
            }
        }

        return -1;
    }

    private int digitSum(int num) {

        int sum = 0;

        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }

        return sum;
    }
}

// Solution is base 6 representation of given num-1
public class Solution {

    public static long nthNumber(int n) {

        int num = n - 1;

        if (num == 0) {
            return 0;
        }

        StringBuilder sb = new StringBuilder();

        while (num > 0) {
            sb.append(num % 6);
            num /= 6;
        }

        return Long.parseLong(sb.reverse().toString());
    }
}
